# Урожай картофеля в Беларуси, сезон 2025 — аналитический кейс

Разбор официальной статистики и оперативных сводок за 2025 год: как
менялся сбор картофеля по ходу уборки, почему итоговая цифра Белстата
в разы превышает данные Минсельхозпрода в моменте, и что это говорит
о структуре производства.

Один и тот же анализ представлен в трёх форматах:

| Часть | Что это | Папка |
|---|---|---|
| 📄 Отчёт | Читаемый HTML-отчёт с графиками и разбором | [`/report`](./report) |
| 🐍 Python | pandas + matplotlib, ноутбук с выводами | [`/python-analysis`](./python-analysis) |
| 📊 Power BI | Интерактивный дашборд + исходные данные | [`/power-bi`](./power-bi) |

## Главный вывод кейса

Итоговый сбор картофеля за 2025 год (3 млн т, все категории хозяйств)
почти в 4,5 раза больше объёма, который отражают оперативные сводки
Минсельхозпрода по организованному сектору (675 тыс. т). Разница —
это объём, который с самого начала не попадает в ежедневный
мониторинг: его дают преимущественно крестьянско-фермерские и
приусадебные хозяйства. Подробности — в отчёте и в ноутбуке.
