## Известные пробелы в данных

- Нет единой итоговой урожайности картофеля (ц/га) по всем категориям
  хозяйств за 2025 год — только оперативные срезы по организованному сектору.
- Региональная разбивка раскрыта не по всем 6 областям (Гродненская и
  Витебская области объединены в оценочный остаток `"Остальные области*"`).
- Официальной трёхсторонней структуры производства (сельхозорганизации /
  фермерские хозяйства / хозяйства населения) в публичных источниках не найдено.
